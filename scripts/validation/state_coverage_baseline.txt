# from contract.yaml (FSM states for orchestrators; output-class field names
# + published event/topic types for compute/effect/reducer nodes) and diffs
# it against the states asserted in that node's test files (an AST-level
# check: the state literal — a string constant, or an ``EnumX.STATE``-style
# attribute — must appear in a genuine assertion context, never a bare
# ``assert "<state>"``, a self-tautology, or a docstring/comment/import path).
# Every pair below is a pre-existing gap
# that was NOT introduced by the gate landing in OMN-13781 — they are WARN,
# not FAIL, in non-strict (--check-all) mode so the initial gate PR lands
# clean without a 262-node backfill blocking it.
#
# This is a grandfather clause, not a permanent exemption:
#   - `--check-changed <ref> --strict` (the required CI gate + pre-commit
#     hook) does NOT consult this file's WARN downgrade for directly
#     modified nodes — touching a baselined node means its coverage must be
#     fixed now, not carried forward.
#   - Regenerate the trailing body mechanically:
#       uv run python scripts/validate_state_coverage.py --check-all --json \
#         | python3 -c "import json,sys; d=json.load(sys.stdin); \
#           print('\n'.join(sorted(f\"{r['node']} {s}\" for r in d['results'] \
