# OmniMarket

OmniMarket provides portable ONEX workflow packages and contract-driven automation.
Documentation: [public knowledge base](https://github.com/OmniNode-ai/knowledge_base).

The proposed RightModeler model-swap service integration is evidence-only.
Its draft [operator runbook and validation guide](https://github.com/OmniNode-ai/knowledge_base/pull/117) describe the required service endpoint, package releases and pilot inputs.
