# OmniMarket

OmniMarket provides portable ONEX workflow packages and contract-driven automation.
Documentation: [public knowledge base](https://github.com/OmniNode-ai/knowledge_base).

Install the `onex` command line on macOS or Linux:

```bash
curl -fsSL https://omninode.ai/install.sh | bash
```

The installer is [packages/omninode-onex/install.sh](packages/omninode-onex/install.sh); supported platforms are in the knowledge base.
